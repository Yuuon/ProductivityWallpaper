Create ThemeService.cs implementing IThemeService:

Constructor: inject nothing (service is self-contained)

Core operations:
1. LoadThemeAsync:
   - Path: %AppData%/ProductivityWallpaper/Themes/{themeName}/theme.json
   - Deserialize JSON to ThemeManifest
   - Call Resources.ValidateAll() to mark missing files
   - Return manifest or null if not found

2. SaveThemeAsync:
   - Ensure theme folder exists
   - Update theme.ModifiedAt = DateTime.Now
   - Serialize to JSON with indented formatting
   - If isBackup: save to theme.json.backup instead
   - Use File.WriteAllTextAsync with UTF8 encoding

3. CreateThemeAsync:
   - Create theme folder
   - Create new ThemeManifest with given name
   - Save initial theme.json
   - Return manifest

Import operations:
4. ImportResourceAsync:
   - Compute CRC32 hash of file (System.IO.Hashing.Crc32)
   - Check if hash exists in current theme
   - Create ResourceEntry with SourcePath = absolute path
   - Set Type based on extension (image, video, audio)
   - Set OriginalName = Path.GetFileName(filePath)
   - Set FileSize = new FileInfo(filePath).Length
   - Return entry

5. ComputeHashAsync:
   - Open file stream
   - Use System.IO.Hashing.Crc32.HashToUInt32
   - Return "crc32:{hash:X8}"

Add XML documentation and error handling.
